# WaterJugProblemSolver
An implementation of the classic Water Jug Puzzle from Artificial Intelligence and graph search theory. Given two jugs of capacities X and Y, this program determines the sequence of pours, fills, and empties required to measure an exact target amount Z.

✨ Features

• Search Algorithms: Supports both Breadth-First Search (BFS) for the shortest path and Depth-First Search (DFS) 

• Dynamic Inputs: Configure custom capacities for Jug A, Jug B, and the target volume

• Solvability Check: Automatically validates if a solution exists using the Greatest Common Divisor (GCD) condition (Z must be a multiple of gcd(X, Y)).

• Step-by-Step Trace: Outputs the complete state transitions (A, B) from the initial state to the goal state
